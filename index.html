About MotoRoute

MotoRoute is a premium, open-source motorcycle routing tool designed to help you plan the perfect ride.

Techniques Used

  • Core Logic: 100% Client-side JavaScript. No backend server is required! Hosted entirely on GitHub Pages.
  • Routing Engine: BRouter API, powered by OpenStreetMap data.
  • Map Rendering: Leaflet.js with Thunderforest maps.
  • Traffic Data: Live integration with the TomTom Traffic API.
  • Spatial Math: Turf.js for complex route simplification, intersection calculations, and dead-end/loop removal.

Built with ❤️ in the Netherlands.
